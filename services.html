Our Services

We offer clear starting prices with no surprises.

Every service has a clear starting price. You'll always know roughly what to expect before we start. No hidden fees, no surprise bills.

IT Health Check

Starting from $250

Not sure what shape your IT is in? We review your computers, email, network, and backups and give you a clear written report with honest recommendations - no fixes included, just a clear picture.

What's included

  • Review of all devices and users
  • Email and domain check
  • Network overview
  • Backup status and written recommendations

Not included: Any fixes or changes - those are quoted separately.

Professional Email & Custom Domain

Starting from $200 + from $40/mailbox

Get a proper business email address like you@yourcompany.com set up on Microsoft 365 or Google Workspace. Looks professional, works reliably, and you own it.

What's included

  • Domain configuration
  • DNS setup
  • Mailbox creation and validation
  • Platform setup guidance

Not included: Email migration from old systems, ongoing administration, and licensing costs billed by Microsoft or Google.

Email Migration

Starting from $150 per mailbox

Moving from an old email system to a new one? We transfer your existing emails, folders, and contacts with minimal disruption to your business.

What's included

  • Mailbox data transfer
  • Post-migration validation
  • DNS cutover
  • Completion sign-off

Not included: Email cleanup/organization, recovery of deleted emails, or ongoing support.

Computer Setup & Data Migration

Starting from $300 per device

New computer for you or a new employee? We set it up properly, install what you need, and transfer your files so you can get back to work immediately.

What's included

  • OS configuration
  • Essential application setup
  • Approved data transfer
  • Validation and handover

Not included: Data recovery from damaged drives, software licensing, or troubleshooting beyond setup.

Windows 11 Upgrade

Starting from $75 assessment, from $200 upgrade

Windows 10 is reaching end of support. We check if your computers are compatible and upgrade the ones that qualify - keeping your files and programs intact.

What's included

  • Compatibility assessment
  • In-place upgrade for compatible devices
  • Post-upgrade validation

Not included: Hardware upgrades, app troubleshooting, or devices that fail compatibility.

Network & Wi-Fi Setup

Starting from $250 basic, from $500 advanced

Whether you need a basic office network or something more advanced with multiple access points and better security, we set it up properly so it works reliably.

What's included

  • Basic: Router, up to 2 access points, internet connectivity, basic security setup
  • Advanced: Multiple access points, network segmentation, security improvements, documentation

Not included: Cabling installation, ISP troubleshooting, or ongoing monitoring.

Backup Setup & Verification

Starting from $400 per system

Most small businesses don't have a proper backup. We set one up and verify it's actually working so you're protected if something goes wrong.

What's included

  • Backup solution setup (cloud, local, or hybrid)
  • Initial verification
  • Documentation of what is protected

Not included: Ongoing monitoring, restore testing, or data recovery services.

Hourly IT Support

  • Recommended next steps

Not included: Guaranteed resolution, project-sized work, or server/infrastructure changes.
